# Asset Canvas

Here is a detailed, structured prompt you can copy and paste into your AI website builder (like v0, Bolt, Lovable, or Framer) to replicate this design.

System & Architecture Prompt:

Build a modern, sleek digital marketplace website for stock assets named "Zastock". The UI features a high-contrast theme split, switching from a deep dark mode aesthetic at the top to a clean light mode layout as the user scrolls.

1. Navigation & Header

Navbar (Dark Background):

Left: Brand logo "Zastock" with a small green icon.

Center: Links for "Home", "About", "Blog", "Pages".

Right: Lock/login icon and a bright mint-green CTA button labeled "Become An Author".

Hero Section (Dark Background):

Large, bold headline: "Use My Collections For A Stunning Site."

Search Bar: Dark input field with a search icon, placeholder "Search our curated collection", and a mint-green CTA button labeled "Browse Collections".

Secondary Tabs: Minimalist tabs for "Image", "Illustration", "Video".

2. Main Asset Gallery (Dark Theme)

Category Filter Pills: Rounded pill tags for filters: "All" (active white background), "Sports", "Architecture", "Fashion", "Interiors", "Animals", "Lifestyle", "Travel", "Nature".

Masonry Grid: A dynamic 4-column masonry grid displaying media preview cards with rounded corners (border-radius: 16px).

Section CTA: A centered mint-green button at the bottom of the grid labeled "View All".

3. Featured / "Most Downloading" Section (Light Theme)

Transition: Smooth gradient background shift from pitch dark to crisp off-white/light gray.

Header: Title "Most Downloading" with top-right pill toggles ("Image", "Video", "Illustration").

Card Layout: Asymmetric grid layout with large hero preview cards showing creator details (avatar, name "Corey Taylor", date, price "$1.00", and download counts/icons). Glassmorphic overlay details on hover.

4. "Why We're Different" Section (Light Theme)

Section Header: Label "ZASTOCK EXCLUSIVE", bold title "Why We're Different", and a top-right mint-green CTA button "Become An Author".

Feature Grid: 2x2 grid of elevated white floating cards with subtle drop shadows, rounded corners, and soft pastel/mint blur glows in the background:

Card 1 (Camera Icon): "Share Your Creativity"

Card 2 (Dollar Icon): "Get Paid For Your Photos"

Card 3 (Palette/Asset Icon): "120,000 Design Assets"

Card 4 (Growth Icon): "Grow Your Personal Brand"

Design Tokens & Styling Guidance

Color Palette:

Primary Dark: #0A0A0C

Accent/CTA: Mint Green (#10B981 / #00E676)

Card Backgrounds (Light Mode): #FFFFFF on #F8FAFC

Typography: Bold, geometric modern sans-serif font for headlines; clean readable sans-serif for body text and metadata.

UI Details: Smooth hover scale effects on image grid items, rounded pill badges, and soft blurred background gradients.
